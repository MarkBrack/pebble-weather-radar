Rain Radar Map Prototype

Browser-only experiment for validating the Pebble-targeted map/radar pipeline before translating it into PebbleKit JS. It fetches the latest RainViewer frame, builds a sharper base map from OpenStreetMap tiles at mapZoom + 1, restyles the basemap into a dark neutral palette, maps rain into fixed Pebble-safe intensity buckets, and crops a Pebble Time 2-sized 200 × 228 window around the user.

2x pixel inspector of the 200 × 228 crop
  • Current RainViewer docs describe the centred endpoint as {path}/{size}/{z}/{lat}/{lon}/{color}/{options}.png.
  • The radar layer is a single centred image, not tiled.
  • The map layer is built from OSM tiles at mapZoom + 1, then simplified into a dark neutral Pebble-style basemap.
  • The Pebble output is a centre crop from the larger composite; it is not scaled from a tiny source.
  • Rain colours are remapped to a fixed six-step Pebble palette so the basemap does not compete with precipitation.
